# FouskaCTF 🚩
Your family friendly CTF guide.

## 📖 About

Welcome to FouskaCTF! This is a comprehensive guide for Capture The Flag (CTF) players, especially those participating in picoCTF competitions. This repository contains step-by-step solutions and common solving techniques for various CTF challenges based on my approach to the ones I've solved.

## 🎯 Purpose

This guide aims to:
- Help beginners learn common CTF solving techniques
- Provide step-by-step walkthroughs of CTF challenges
- Share practical approaches to different types of security problems
- Build a community resource for CTF players

## 📚 Categories

The challenges are organized into the following categories:

### 🔍 [Forensics](./Forensics)
Digital forensics challenges involving file analysis, steganography, memory dumps, and network packet analysis.

### 🔐 [Cryptography](./Cryptography)
Challenges involving encryption, decryption, encoding, hashing, and cryptographic protocols.

### 🌐 [Web Exploitation](./Web-Exploitation)
Web security challenges including SQL injection, XSS, CSRF, and other web vulnerabilities.

### 💾 [Binary Exploitation](./Binary-Exploitation)
Binary and memory exploitation challenges including buffer overflows, format strings, and shellcode.

### 🔧 [Reverse Engineering](./Reverse-Engineering)
Challenges requiring analysis and reverse engineering of compiled programs and binaries.

### 🎲 [General](./General)
Miscellaneous challenges that don't fit into other categories, including OSINT and puzzle-solving.

## 🚀 Getting Started

If you're new to CTFs, start here:

1. **Learn the Basics**: Understand what CTFs are and the different challenge types
2. **Set Up Your Environment**: Install necessary tools (Python, Python libraries, text editors, hex editors, etc.)
3. **Start Simple**: Begin with easier challenges in the General or Forensics categories
4. **Read Writeups**: Learn from others' solutions and approaches
5. **Practice Regularly**: Join platforms like picoCTF, HackTheBox, or TryHackMe

## 📝 Challenge Format

Each challenge writeup follows this structure:
- **Challenge Name**: The name of the CTF problem
- **Category**: The type of challenge
- **Points**: Difficulty level or point value
- **Description**: The challenge description
- **Solution**: Step-by-step walkthrough
- **Flag**: The final answer (in spoiler tags when appropriate)
- **Tools Used**: List of tools and resources
- **Learning Points**: Key takeaways from the challenge

## 🛠️ Recommended Tools

Here are some essential tools for CTF challenges:

### General
- Python 3 with common libraries (pwntools, requests, etc.)
- Text editor (VS Code, Sublime, Vim)
- Command line skills (bash, grep, sed, awk)

### Forensics
- Wireshark (network analysis)
- Binwalk (firmware analysis)
- Exiftool (metadata extraction)
- Steghide (steganography)
- Volatility (memory forensics)

### Cryptography
- CyberChef
- OpenSSL
- Python cryptography libraries
- RsaCtfTool

### Web Exploitation
- Burp Suite
- Browser Developer Tools
- curl/wget
- SQLMap

### Binary Exploitation & Reverse Engineering
- GDB with pwndbg/gef
- Ghidra
- IDA (Free version)
- Radare2
- pwntools
