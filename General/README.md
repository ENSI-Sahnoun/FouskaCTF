# General Challenges 🎲

General challenges encompass a variety of problem types that don't fit neatly into other categories, including OSINT, puzzles, trivia, and miscellaneous security topics.

## Common Techniques

### OSINT (Open Source Intelligence)
- **Google dorking**: Advanced search operators
- **Social media investigation**: Finding information on platforms
- **WHOIS lookups**: Domain information
- **Wayback Machine**: Historical website data
- **Image reverse search**: Finding image sources

### Puzzles & Logic
- **Ciphers**: Various encoding schemes
- **QR codes**: Quick response code scanning
- **Mathematical puzzles**: Number theory, algorithms
- **Logic puzzles**: Deductive reasoning

### Miscellaneous
- **Git challenges**: Repository history analysis
- **Esoteric languages**: Brainfuck, Whitespace, etc.
- **Trivia**: Security and computer science knowledge
- **Sanity checks**: Easy first-blood challenges
