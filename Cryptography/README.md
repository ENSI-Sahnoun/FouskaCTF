# Cryptography Challenges 🔐

Cryptography challenges involve breaking ciphers, understanding encryption schemes, and exploiting cryptographic weaknesses.

## Common Techniques

### Classical Ciphers
- **Caesar cipher**: Shift cipher
- **Substitution ciphers**: Letter replacements
- **Vigenère cipher**: Polyalphabetic cipher
- **Transposition ciphers**: Rearranging characters

### Encodings
- **Base64**: Common encoding scheme
- **Hex encoding**: Hexadecimal representation
- **URL encoding**: Percent encoding
- **ASCII/Unicode**: Character encodings

### Modern Cryptography
- **RSA**: Public key cryptography
- **AES**: Symmetric encryption
- **Hashing**: MD5, SHA-1, SHA-256
- **Digital signatures**: Authentication schemes

### Common Attacks
- **Frequency analysis**: For substitution ciphers
- **Known plaintext attack**: When you know part of the message
- **Weak RSA**: Small exponents, common modulus
- **Hash collisions**: MD5, SHA-1 weaknesses

## Useful Tools

- **CyberChef**: The Cyber Swiss Army Knife
- **dcode.fr**: Online cipher solver
- **RsaCtfTool**: RSA attack tool
- **hashcat**: Password cracking
- **john**: John the Ripper password cracker
- **OpenSSL**: Cryptographic toolkit
- **Python**: pycryptodome, cryptography libraries

## Tips

1. Identify the cipher/encoding first
2. Try common encodings (Base64, Hex) first
3. Use frequency analysis for substitution ciphers
4. For RSA, check for small exponents or small primes
5. CyberChef can auto-detect many encodings
